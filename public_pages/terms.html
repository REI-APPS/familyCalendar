Termos & Política de Privacidade

Última atualização: 15 de Junho de 2026

1. Aceitação dos termos

Ao instalar, aceder ou utilizar a aplicação Agenda da Família ("a App"), o utilizador concorda com estes Termos de Utilização e com a Política de Privacidade descrita neste documento. Se não concordar, deve deixar de utilizar a App.

2. Descrição do serviço

A Agenda da Família é uma app móvel para organização de horários e tarefas entre membros de uma mesma família. Permite criar contas, criar ou aderir a uma família, gerir turnos, tarefas e convidar outros membros por email.

3. Contas de utilizador

Para usar a App é necessário criar uma conta com um email válido e uma password. O utilizador é responsável por manter a confidencialidade das credenciais e por todas as ações realizadas com a sua conta.

Só o proprietário da família pode remover outros membros. O utilizador pode apagar a sua própria conta em qualquer momento a partir do ecrã "Ajustes".

4. Dados que recolhemos

Recolhemos apenas os dados necessários para prestar o serviço:

  • Email e password (para autenticação)
  • Nome da família e dos membros (definidos por ti)
  • Turnos, tipos de horário e tarefas que crias
  • Idioma escolhido (Português, English ou Español)
  • Data e hora de criação/alteração dos registos

Não recolhemos dados de localização, contactos, câmara, microfone, ou identificadores publicitários.

5. Como usamos os teus dados

  • Para autenticação e para te manteres com sessão iniciada
  • Para mostrar a agenda partilhada aos membros da mesma família
  • Para enviar emails de convite (só quando és tu a convidar alguém)
  • Para melhorar a estabilidade e segurança do serviço

Não vendemos, alugamos, nem partilhamos dados pessoais com terceiros para fins publicitários.

6. Onde ficam guardados os teus dados

Os dados são armazenados numa base de dados PostgreSQL gerida pela Supabase Inc. (EU-West). Aplicamos políticas de segurança ao nível da linha (Row Level Security) que garantem que cada utilizador só consegue ver os dados da sua própria família.

Os emails de convite são enviados através do serviço Resend. Os emails são apagados dos nossos sistemas após 30 dias.

7. Retenção de dados

Os dados são mantidos enquanto a tua conta estiver activa. Ao apagares a conta, todos os dados associados (membros criados por ti como owner, horários e tarefas) são apagados no prazo máximo de 30 dias. Ver Apagar Conta.

8. Os teus direitos (RGPD)

Podes, a qualquer momento:

  • Aceder aos teus dados diretamente na App
  • Corrigir dados incorretos (Ajustes → Editar Perfil)
  • Apagar a tua conta e dados (Ajustes → Apagar Conta)
  • Pedir uma cópia dos teus dados enviando um email para suporte@familycalendar.grouprei.com
  • Retirar o consentimento (basta apagar a conta)
